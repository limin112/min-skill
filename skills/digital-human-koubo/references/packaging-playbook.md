# 包装手法库（来自 4 类头部博主逐帧实测）

2026-10 拆了 25 支：英文顶流节奏派（MrBeast / Mark Rober / Ryan Trahan）、科技评测质感派（MKBHD / 影视飓风 / 何同学）、知识解说动画派（Johnny Harris / Vox / Kurzgesagt / 回形针）、中文口播网感派（半佛仙人 / 差评 / 毕导，对照小Lin说）。完整报告（每条手法都有时间戳证据和参数）在 `references/research/`。这里是能直接拿来用的结论；每条手法对应的组件见 `references/packaging.md`。

## 1. 节奏：先定目标，再排包装

| 流派 | 切/分钟（实测） | 中位镜头 | 新视觉事件间隔 | 我们对应的风格 |
|---|---|---|---|---|
| MrBeast | 24–25 | 1.8 秒 | 前 30 秒每 3.3–5 秒一个 | B 竖屏快节奏、E 冷开场 |
| Mark Rober | 30–50 | 1.0–1.2 秒 | 字跟鼓点 0.3 秒一拍 | B「热闹」档、片头 |
| Ryan Trahan | 16–17 | 2.9 秒 | 切少但图形事件多 | B「标准」档、vlog 口吻 |
| MKBHD | 5.5–6.7 | 约 8 秒 | 画面几乎不加字 | C 发布解读「克制」版 |
| 影视飓风 / 何同学 | 12–17 | 约 3 秒 | 图形 + B-roll 撑节奏 | C 发布解读、D 教程 |
| Johnny Harris / Vox | 10–26 / 13 | 3 秒左右 | 前 60 秒最密，正文放慢 | A 解说、D 教程 |
| Kurzgesagt / 回形针 | 4.5–7 / 7–10 | 不硬切，镜头内一直在动 | 每 4–5 秒一拍 | A 解说的动画段 |
| 半佛 / 差评 / 毕导 | 10–17 | 约 3 秒 | 一句话一张图 | A、B |

**通用规则**
- 切数可以低，**刺激不能断**：前 30 秒每 3–5 秒要有一个新视觉事件（数字大字、卡片、地图、转场、反应、跳切推近）。
- 单机位数字人最便宜的节奏来源是 **PunchInHost**：同一条口播按句子边界硬切 1.0 / 1.18 / 1.32 倍景别（可左右偏置），不用重新生成。
- 前 60 秒最密，正文可以放慢；长视频每 2–5 分钟一张章节卡。
- 主播全屏一次不超过 12 秒；长段落拆成「全屏 → 小窗图表 → 全屏」或「主播 + 身旁悬浮物」。

## 2. 开场公式（30 秒钩子）

四派归纳成一个能套的模板（括号里是可用组件）：
```
0–3 秒    命题或动作，不问好、不报名字、不放 Logo（SlamText / NumberSpike / TeaserColdOpen / SearchTyping / ColdOpenFreeze）
3–15 秒   把观点变成看得见的证据：数字、截图、小实验、观众自己的搜索记录（EvidenceCard / DocFocus / Counter / ReviewCards）
15–30 秒  主问题写在屏幕上，或者来一句反转（TiltLine / ChapterCard / WordStack）
22–60 秒  第一张章节卡 = 冷开场结束（ChapterCard / TornStrip）
```
- 英文顶流：2 秒内说出核心名词 → 0.7–5 秒数字钉子 → 2–12 秒先给结局快闪 → 8–17 秒赌注加码 → 13–20 秒反应三连 → 25–30 秒进章节。
- 科技评测（中文两家）：主题句 → 小实验 → 反转 → 喊「开始」→ 4–8 秒片头（音乐比口播响 3–5 LU）。
- 网感派：先给画面、后报身份；片名出现在 4–70 秒之间，内容越「现象驱动」片名越晚。
- **数字人专用**：开头 5–20 秒可以完全不露脸（B-roll / 字卡），把口型最难的开场段盖过去；数字人 3–10 秒内入场，并尽早「指向」证据。

## 3. 字幕和屏幕文字
- 中文竖屏（B）：保留逐字花字字幕（字号、描边见 references/huazi.md）。
- 中文横屏解说（A/D）：底部字幕 50–54 px、800 字重、y≈92%，单行 12–18 字，硬切不淡入。
- 发布解读（C）可以学差评：**不烧录字幕**，屏幕留给证据卡和数字（平台 CC 字幕兜底）。
- 英文和质感派都不铺满字幕：字只给 **数字、关键词、身份 / 时间** 三类信息。
- 每个数据都挂出处（SourceTag：左下小字 + 红点，停 3–5 秒）。

## 4. 声音
- **BGM 床从头铺到尾**（中文头部实测几乎没有静音），人声出现时压到约 -18 dB，句间停顿回到 -14 dB。
- **音效只给事件**：揭示、碎裂、投票、数字落定、卡片弹出。中文网感派每分钟 1–3 个就够，不要每个切点都挂「嗖」；英文快节奏可以更密（数字落定配低频 boom）。
- **揭示前刻意静音 0.6–1.0 秒**（毕导实测），每段末尾留一次 0.4–0.8 秒停顿给笑点或反转。
- 片头 / sting 比口播响 3–5 LU，结束前 6 帧淡回。
- 成片响度：竖屏短视频 -14 LUFS；横屏解说 / 教程 -16 LUFS。

## 5. 号召与结尾
- 号召至少两次：一次放在前 15 秒或「揭晓前」（PollPop、GlitchInterstitial「点赞关注」0.5 秒），一次在结尾。
- 结尾回扣开场（同一个画面、同一个问题、同一个角色），不另起新话题；花絮彩蛋放在号召之后。
- 长视频结尾前回到复盘板（RecapBoard）把学到的列一遍。

## 6. 红线（不照搬）
- **不用网络梗图、影视剧 / 动画截图、明星表情包**：梗图窗和反应贴纸用原创素材——数字人定妆图做 20 种表情贴纸、原创 IP 动物表情包（AI 生成），或 Noto 动态表情。
- **不用真实人物照片做名牌**（肖像权）：用无脸剪影 / AI 角色，名牌照常写，并标「示意角色」。
- **截图里的品牌 Logo 虚化**；不仿 Google / 百度等搜索框品牌（SearchTyping 是中性样式）。
- **不编数据**：GlassPanel / SpecCard / Counter 里的数字必须是实测或有出处；示意数据要在画面上标「示意」。AI 生成的产品镜头不能冒充实拍实测。
- 「To Be Continued」箭头、各家片头 sting、布景、口头禅原句都不照搬，用自绘中文版本。
