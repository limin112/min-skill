# 中文口播网感派

样本：硬核的半佛仙人、差评君、毕导THU 各 2 支（近 20 支中 5–25 分钟内播放最高 1 支 + 最新 1 支）。原始数据在 `~/Desktop/packaging-research/ana/<频道>_<ID>/`（stats.json、hook.jpg、shots_XX.jpg），放大帧在 `ana/frames/cn/`。小Lin说的结论见 `~/.claude/skills/finance-explainer/references/`，本报告只写它没覆盖的部分，并逐条对比。

一句话结论：**小Lin说的包装是「图表舞台 + 主播缩放」，网感派是「每 3 秒换一个情绪道具」**。三家剪辑速度和小Lin说差不多（中位镜头都在 3 秒左右），差别在每个镜头里放的东西：半佛放梗图，差评放带品牌色框的证据截图，毕导放实验和 AI 生成的夸张画面。三家都用**冷开场**，先抛现象，再报身份。

## 共性开场公式

```
[冷开场 3–40 s：无字视觉钩子 / 发问 + 三连证据 / 情景短剧 / 亲历异常现象]
  → [身份仪式 1–3 s：固定口头禅或品牌片头，可以顺手塞三连号召]
  → [一句话论点或问题（问句）]
  → [第一个具体数字或案例，2 秒内配上画面]
```

- 片名出现的时间：半佛 4.0 s，差评约 23.5 s，毕导 40–71 s。内容越「现象驱动」，片名出得越晚。
- 小Lin说是主播开场直接聊加私信卡点题，**网感派先给画面、后报身份**。数字人做冷开场有个好处：开头 5–20 秒可以完全不露脸，口型最难的开场段用 B-roll 盖过去。
- 三家的冷开场都有一条「证据链」，由 3 个以上的具体事实组成（差评：销量、营收、退市、零头；毕导：绿灯、车流、转弯），不是一句空泛的断言。

## 手法清单

### 1. 黑底梗图窗 + 固定底字幕（半佛式图文轰炸）
- 长什么样：纯黑 16:9 画布，梗图/动图居中偏上，宽约 45–47% W、高约 75–80% H，顶边距约 5% H。梗图自带一句梗字：白色粗黑体加黑描边，压在图的上沿或下沿，字高约 7% H；或者用「白底条 + 黑字 + 下面一张图」的格式。口播字幕独立固定在 y≈92% 处。梗图之间硬切，没有入场动画。右上角常驻小号白色频道水印，带黑描边。
- 证据：半佛 4EcnJHcZyCo 0:07–0:45（16 张）、2:16.6（白底条格式）、3:34.6（「朋友：…我：」对话格式）；GxNsnH4593E 0:11.5–3:20（约 50 张）。
- 频率：约 14 张/分钟（4Ecn 14.2、Gx 14.0 切/分钟，基本一镜一图），单张中位 3.0 s，p10 1.5 s。
- 配合声音：底下一直铺 BGM，没有停顿（静音段 0–2 处）。切点上的瞬态只比随机时刻略多（8% 对 2%、4% 对 3%），说明**不是每张图都配音效**。
- 为什么有效：每句话都给一个能代入的情绪表情，观众不用看懂图表也能一直看下去。
- 怎么在 Remotion 里实现：`<MemeWindow src caption captionPos="top|bottom|header" />` 放在 `<BlackStage>` 里，拍表一句台词对应一张图（`at`）。素材用 AI 生成的原创动物反应图或 2–4 s 短动图（Renoise 便宜模型），再加原创吉祥物贴纸。**不要用网络流行梗图**（猫狗原图、熊猫头都有作者版权），换成「同一只原创 IP 动物 × 20 种表情」的素材包。
- 适合：B（竖屏可以改成上图下字）、A（做「吐槽段」插段）
- 优先级：P0

### 2. 冷开场定格 + 片名卡（失败瞬间 → 去色 → 未完待续）
- 长什么样：0–4 s 全屏动作片段 → 定格，0.2 s 内去色到灰度 → 左下角出箭头贴纸（白底黑描边手写体）→ 中央深灰半透明圆角框（宽约 66% W，圆角约 16 px，rgba(40,40,40,.7)），白色粗黑体两行片名，字高约 9% H，下方小字期号 → 2.5 s 后接 0.5 s 雪花噪点转场。
- 证据：半佛 4EcnJHcZyCo 0:00–0:06.6；GxNsnH4593E 0:00–0:07（多了雪花噪点 6.5–7.0 s）。
- 频率：每期固定 1 次，是品牌仪式。
- 配合声音：开头 0–7 s 只有音乐（whisper 只转出 [音乐]），定格那一下推测有一个音乐落点。
- 为什么有效：4 秒内交代清楚题目，期号还能强化「连载」的感觉。
- 怎么在 Remotion 里实现：`<ColdOpenFreeze clip freezeAt={4} title={[l1,l2]} vol="VOL.012" arrowText="未完待续" />`，用 CSS `filter: grayscale()` 插值，噪点用 canvas 程序化生成。原版的「To Be Continued」箭头是 JoJo 动画的梗，**改成自绘中文箭头**。动作片段用 AI 生成的原创失败瞬间。
- 适合：A、B、C
- 优先级：P0

### 3. 证据截图飞入：品牌色描边 + 鼠标指针 + 数值签（差评式）
- 长什么样：截图从画面中心 20% 大小飞入，放大到约 55% W，背景是深灰渐变（#2a2a2a→#1a1a1a）；外面套 4 px 薄荷绿描边框（实测 #38C878 到 #48F8B8）；右下角跟一个白色鼠标指针；镜头推近关键数据点，弹出深蓝底白字粗体数值签（字高约 4% H）。文档常做 3D 透视倾斜（rotateY 约 −20°、rotateX 约 8°），用翻页或撕纸切到下一张。
- 证据：差评 UGHTnMPZsAM 0:03–0:10（图表 + 指针 + 「346.8万台」）、0:16（纳斯达克公告透视）、3:31.3（年报截图）；g00-PGtexNg 1:49.9（新闻页 + 绿色高亮）、7:18.9（透视文档）。
- 频率：差评每分钟约 1–3 张证据截图，开场 23 秒内就有 4 张。
- 配合声音：BGM 底子上叠轻微的「嗖」，推测和飞入同步；实测切点瞬态和随机时刻相当，所以这类音效很轻。
- 为什么有效：鼠标指针加描边，营造出「我刚查到的」第一现场感，可信度比单放截图高。
- 怎么在 Remotion 里实现：`<EvidenceCard src frameColor="#3CF0A0" cursor focus={{x,y,scale}} label="346.8万台" tilt={-20} />`，用 spring 实现飞入（damping 18），推近用 `interpolate` 驱动 scale 和 translate。素材是自己截的网页或报告（公开信息截图），截图里的品牌 Logo 要虚化。小Lin说的 Doc 只有逐行标黄，这里多了**飞入路径、品牌色框、指针、透视**。
- 适合：A、C（发布解读首选）、D
- 优先级：P0

### 4. 品牌色荧光笔高亮（文档 + 自打字卡都用）
- 长什么样：差评用薄荷绿 #38F898 色块垫在原文句子后面（不透明，盖住整行高度）；毕导在自己打的题干卡上，把关键短语垫成橙色块 #E8862A，字保持白色。从左往右擦出，约 0.3 s。
- 证据：差评 g00-PGtexNg 5:50.5（文档绿条 + 圆形主播小窗）、UGHTnMPZsAM 5:09.1；毕导 vwyU2jrc3W4 0:44.6、3:01.5（题干卡橙块）。
- 频率：每期 3–8 处。
- 配合声音：推测有轻「刷」声，未实测。
- 为什么有效：颜色固定成品牌色，观众一眼就知道这是重点，同时也在强化品牌。
- 怎么在 Remotion 里实现：小Lin说的 Doc 组件加上 `hlColor` 参数，再新增 `<ProblemCard lines hl=[[start,end]] />`，题干卡左对齐，白色粗体约 6.5% H，叠在暗化的背景画面上（brightness .55）。
- 适合：A、C、D
- 优先级：P0

### 5. 弹幕投票 / 「扣 1 扣 2」互动指令（毕导）
- 长什么样：主播抠像放在 B-roll 右下角（约 35% H），口播让观众在弹幕里打 1 或打 2。画面右侧弹出巨大的绿色「1」（白描边，约 10% H，带轻微旋转），说「不同意」时换成「2」。
- 证据：毕导 vwyU2jrc3W4 1:50.1–1:54（扣 1）、1:52.8（扣 2）；DN1Jj1rIiJQ 2:30.7、2:44.6、10:57.4 是电视测试卡故障插屏，主播圆形抠像在中间，上面写「点赞关注」，每次只有 0.4–0.6 s。
- 频率：每期 1 次投票，加 2–3 次一闪而过的点赞插屏。
- 配合声音：故障插屏推测带电视干扰声。
- 为什么有效：在答案揭晓前让观众先站队，评论和弹幕会明显增加，观众也会为了看答案留下来。

## 声音设计

实测方法：16 kHz 单声道，10 ms 帧。统计低于 −45 dBFS、持续 0.35 s 以上的静音段；用 2 kHz 以上的频谱通量检测瞬态，看切点前后 ±0.12 s 内有没有瞬态，再和 2000 个随机时刻对比。结果：

| 视频 | 静音段数 | 每秒 10 分位响度中位 | 切点有瞬态 / 随机时刻 |
|---|---|---|---|
| 半佛 4Ecn | 2（首尾） | −35.8 dBFS | 8% / 2% |
| 半佛 Gx | 0 | −35.1 | 4% / 3% |
| 差评 UGHT | 0 | −33.8 | 10% / 14% |
| 差评 g00 | 2 | −36.0 | 7% / 5% |
| 毕导 vwyU | 3 | −32.6 | 12% / 12% |
| 毕导 DN1J | 6（2:12、10:52 等） | −34.6 | 16% / 17% |

结论：
1. **BGM 垫底从头铺到尾**，底噪中位在 −36 到 −33 dBFS，全片几乎没有真正的静音。我们的 BGM 避让可以压到口播下方约 −18 dB，但不要关掉。
2. **不是每个切点都配「嗖」**：切点上的瞬态比例和随机时刻差不多，只有半佛略高（8% 对 2%）。音效只用在事件上（揭示、碎裂、投票、故障插屏），每分钟 1–3 个就够，别在每个切点上挂音效。
3. 毕导用**刻意的静音**做揭示：DN1J 2:12.15 静音 0.61 s（手电照亮砧板的暗角镜头），10:52.8 静音 1.02 s。可以写成拍表字段 `"silence": 0.6`，让 BGM 在揭示前断开。
4. 半佛开场 0–7 s 只有音乐，没有口播，冷开场是靠音乐撑的。
5. 我只做了波形统计，没有逐声去听，所以具体是「叮」「啪」还是罐头笑声无法确认，以上都标了「推测」。毕导片尾有 BGM 名单卡（vwyU 9:24.9，13 s），说明他每期换好几首曲子，曲目切换要另外做频谱分析才能确认。

| 半佛 | 开头 9 s（贴纸字）+ 结尾最后 2.4 s | 片尾回到镜子吉祥物，说一句感谢点赞关注，接一句下期再见，没有总结段。最后一个观点说完立刻结束 |
| 差评 | 结尾 12 s 口播 | 一键三连、评论区互动、关注公众号、拜托关注，然后接复古显示器制作名单和台标 sting。短新闻那期（UGHT）完全没有号召，用一句升华结束，背景是产品 B-roll 蒙太奇 |
| 毕导 | 中段 2–3 次 0.5 s 故障插屏「点赞关注」+ 结尾口播三连 | 结尾回扣开场短剧，给荒诞场面一个结局（vwyU 用 AI 画面做了一个夸张收尾），然后是 BGM 名单卡和花絮彩蛋（DN1J 片尾：办公室花絮画中画 + 右侧斜体小字备注实际花了多少钱） |

可复用规则：① 号召至少出现两次，其中一次放在前 15 秒或中段的「揭晓前」；② 片尾用回扣开场的方式收尾（短剧、吉祥物），不要另起一个新话题；③ 花絮彩蛋放在号召之后，奖励看到最后的人。

## 数字人口播用不上或不该照搬的

| 原手法 | 问题 | 原创替代 |
|---|---|---|
| 半佛整片用网络猫狗梗图、熊猫头表情 | 原图和二创都有作者，商用有风险，平台也可能判搬运 | 原创 IP 动物（一只固定形象）加主播本人卡通形象，各做 20 种表情的 AI 表情包库（手法 15） |
