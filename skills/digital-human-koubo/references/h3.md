# MiniMax H3（本地 ComfyUI）

H3 是 MiniMax 开源的音画联合生成模型：一张首帧 + 一段提示词，**画面和声音（台词、环境声）一起出**，口型天然对得上。单段 4–15 秒，24 fps，32 kHz 立体声。

## 工作流（h3.py 自动拼）

```
UNETLoader(fl2va) → MiniMaxH3TurboLoRA(v4_step600_ema, 1.0, low_vram=False)
  → BasicGuider ← MiniMaxH3ImageToVideo(clip, vae, prompt, W, H, length, first_frame)
  → SamplerCustomAdvanced(RandomNoise, MiniMaxH3TurboSampler, BasicScheduler(simple, 8))
  → LTXVSeparateAVLatent → VAEDecode / VAEDecodeAudio → CreateVideo(24fps) → SaveVideo
```
- Turbo 路线**不要再接 MiniMaxH3SigmaShift**：Turbo Sampler 自己处理音视频双时间表（video shift 12 / audio shift 3），叠上会重复 shift 把音频搞坏。
- 原版路线（`--no-accel`）：SigmaShift(12, 3) → KSampler(euler, normal, 20 步, cfg 1)。
- 帧数吸附到 17k+5（124 = 5 秒 … 362 = 15 秒）。宽高 32 的倍数，`W×H ≤ 768×1344`。
- 首帧是**直接拉伸**到画布的：h3.py 先在本机居中裁切到目标比例，再传上去。

## 提示词结构（官方 h3-prompt-writing skill，I2VA）

```
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.

integrated_multimodal_description: [Shot 1] <画风>, <景别>. The video begins exactly from <Picture 1>: <人物身份>.
Keep the same face, hair, outfit, <要保住的小特征>, framing, background and lighting as <Picture 1> throughout.
<镜头运动>. <表演>. The <音色描述> (S1), <口音>, looks into the camera and says: <d>[Chinese] 台词原文</d>
After the line she holds a relaxed, natural expression with lips closed until the end. No subtitles ... appear.

overall_soundscape: <环境声>

non_diegetic_music: N/A
```
- 台词放 `<d>[语言] …</d>`，**一字不改**；语言标签用 `Chinese` / `English` / `Japanese`，口音写在 `<d>` 外面（`speaking English with a crisp, refined British RP accent`）。
- 说话人用 `(S1)` 编号，第一次出现时写清音色（年龄、性别、音高、语速）。每个角色的音色描述固定在 cast.json / 角色库的 `voice`，**每段一字不改**，整片音色才稳。
- 配乐留给后期统一铺：`non_diegetic_music: N/A`。
- 镜头词用官方的：`holds a static shot` / `pushes in with small amplitude at slow speed` …
- 动物角色把 `lips` 换成 `beak`（角色的 `mouth: "beak"`），二次元角色画风写 `2D anime, clean cel-shaded animation`。

## 坑
- Turbo 节点比 README 多一个必填参数 `low_vram`（API 里不传会 `required_input_missing`）。
- 第二个实例启动时报 `Could not acquire lock on database comfyui.db`：无害，只是用户数据库被第一个实例锁了。
- `Minimalistic-Comfy-Wrapper-WebUI` 报 `No module named 'gradio'`：原来就有，跟 H3 无关。
- H3 会把台词摊满整段：给的秒数越多念得越慢。按 5 字/秒 + 1.5 秒留白估，实测念得完整自然。
- whisper 对英文段不加 `-ml 1`（逐字切分对英文没意义）；中文段加，便于逐字对齐。
